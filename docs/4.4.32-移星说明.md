# 4.4.32 淬炼移星

## 用法

执行 `/cuilian moveLevel`，左键背包中的来源装备A，再左键目标装备B，最后点绿色确认按钮。点击界面的A/B预览槽可重新选择。装备本体始终在背包，界面只是副本，禁止取出预览、Shift快捷搬运、数字键交换、拖拽。

本次按服主确认的**覆盖模式**实现：A的星级、保护符和宝石整体转到B；A清除这些内容，B原有这些内容直接删除，不叠加、不退还。如果A没有保护符或宝石，B对应内容也会清空。A、B各自的绑定、普通附魔、当前耐久、自定义NBT与其他描述保留在原装备上，不随属性转移。

若宝石包含2.5旧荆棘，清理其对应的原版荆棘附魔；这类旧数据不能区分原先自带荆棘，行为与baoshi 2.6升级相同。

## 配置

首次启动生成 `plugins/NewCustomCuiLianPro/movelevel.yml`，不覆盖已有 `config.yml`、`stone.yml`、`cuilian.yml`、`items.yml`。

- `enabled`：功能开关。
- `cost: 100`：每次成功移星消耗的PlayerPoints点券，必须为非负整数；0免费。
- `same-category: true`：同分类移星，默认武器到武器、头盔到头盔等。分类来自淬炼 `items.yml`。设false允许跨分类，但宝石目标规则仍必须满足。
- `ui.title` / `ui.rows`：标题及1–6行大小。
- `ui.source.slot`、`ui.target.slot`、`ui.confirm.slot`：0开始的槽号，不得重复或超出界面。
- 各按钮的 `material`、`data`、`name`、`lore`：外观，支持`&`颜色和`%cost%`费用占位符。
- `ui.background`：背景填充物。

执行 `/cuilian reload` 重载；成功重载关闭旧移星窗口，避免旧价格继续成交。移星配置错误则保留上一份有效移星配置，首次无有效配置则禁用此界面。旧 `config.yml` 的 `MoveLevelInvTitle` 不再控制新界面，以 `movelevel.yml` 为准。

权限 `cuilian.movelevel` 默认所有玩家可用，可用LuckPerms限制。

## 数据与依赖

星级不再采用旧版的“A星+B星−1”公式，B直接获得A星级，并按B的装备分类重建淬炼属性。数据不能识别、同一背包槽、堆叠装备、宝石不适用于目标时，均在扣款前拒绝。

宝石对接当前 `baoshi-configurable` 的运行时配置/隐藏标记，已用2.6.0验证，不需要更新baoshi。支持稳定标记和可迁移的旧版宝石；不复制普通文字伪造属性。缺少baoshi、接口不兼容、损坏或冲突标记、缺少宝石配置都会拒绝带宝石的移星。未来宝石插件内部接口变化需要同步适配。

宝石数值保留，耐久精魄的隐藏耐久记录改为B当前损耗，不修复B、不沿用A损耗。新旧荆棘转移要求baoshi 2.6或兼容新版。

点券使用PlayerPoints的 `getAPI()` / `look` / `take` / `give`，优先UUID接口，兼容姓名接口；不使用控制台命令假扣款，不自动改用金币。找不到PlayerPoints或扣费接口不兼容时，收费移星不可用。

## 安全与验收

计算在克隆装备上完成；确认前及扣款后再次核对背包原物品，避免操作期间被更换。重复点击不会重复扣款；关闭/退出/重载后等待中的确认失效。扣费失败不写装备，扣费后装备发生变化则退款；写入异常尝试恢复两件原装备并退款。退款接口失败会明确提示玩家并在后台记录人工退款金额。

这不是跨插件数据库事务：PlayerPoints接口抛异常但实际已扣款、服务器硬崩溃或极端回滚失败，需要管理员按日志核对；上线前请备份物品和点券数据。`[MoveLevel]` 为点券操作审计日志，不随普通淬炼调试开关关闭。

已加入离线回归：覆盖移星、保留绑定、自定义数据、保护符、隐藏宝石、耐久基准、目标校验、余额不足、拒绝扣费、重复确认、关闭界面、装备变化、写入故障退款。测试使用服务器/PlayerPoints替身，实际Uranium和服主所用PlayerPoints版本仍需测试服验证。

构建产物为 `dist2/[淬炼]NewCustomCuiLianPro-4.4.32.jar`。首次部署停服替换旧JAR后重启；只需要新增 `movelevel.yml`，不用替换既有淬炼配置。
